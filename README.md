**Island Courier — Nusantara Skies.** A complete, original flight game: fly a
little twin-prop mail plane over an Indonesian archipelago at golden hour.
Thread the glowing rings, mind the fuel gauge, fight the crosswind, and put
her down on the island strips. Three sorties — Ring Run, Island Hop, and the
Storm Courier — with a chase view over recognisable island terrain, a lit
instrument panel (altitude, speed, heading, attitude, fuel, throttle), and
synthesised engine sound. Keyboard and mouse, no network, no build step.

## Run it

```sh
node serve.ts
# then open http://localhost:8080
```

Controls: arrow keys / WASD fly the plane (left/right bank, up/down pitch),
Shift / Ctrl work the throttle, Space is the airbrake, P pauses, M mutes.
